「立即执行」= 强制跑一次并参与灯色判定：执行成功 → 绿灯（并标注来源「手动验证」）；执行失败 → 红灯；从未执行 → 灰灯。 宝塔计划任务真实触发后，来源会变为「URL 调度 / CLI 调度」，同样按成败亮灯。执行需几秒，按钮会显示「执行中…」。

配置方式（二选一）

方式 A：宝塔 Shell 脚本（推荐）

宝塔 → 计划任务 → 添加任务 → Shell 脚本，按任务逐一粘贴（命令首行是任务名注释，不影响执行）：

{volist name="tasks" id="t"}
{$t.name}
{$t.cli}
{/volist}

方式 B：宝塔 访问URL（免 CLI）

把下列地址填进宝塔「访问URL-GET」计划任务（任务类型必须选 GET）：

{volist name="tasks" id="t"}
{$t.name}
{$t.url}
{/volist}
访问密钥：

访问密钥的用途：方式 B（访问 URL）里的 key= 参数，用于证明请求来自你本人—— 防止他人构造同一个地址反复触发任务（例如恶意刷造图，消耗你的模型额度）。方式 A（CLI 命令）不需要密钥。
重置会怎样：立即生成新密钥，所有旧地址当场失效，宝塔里用方式 B 配置的任务需逐个替换成新地址（方式 A 不受影响）。 当前已用方式 A（CLI）的可放心重置。
