API 文档

Lsky Pro 兼容接口，可直接对接 PicGo / Typora / ShareX / 自写脚本。Token 在 个人中心 生成。

鉴权

任选一种（请求头优先）：

X-API-TOKEN: 你的Token
Authorization: Bearer 你的Token

接口列表

方法路径说明
POST/api/v1/upload上传图片（multipart，字段名 file）
GET/api/v1/info/{id}查询图片信息
GET/api/v1/list?page=1&size=20我的图片列表
POST/api/v1/delete/{id}删除图片

上传示例

curl -X POST "{$domain}/api/v1/upload" \\
  -H "X-API-TOKEN: 你的Token" \\
  -F "file=@photo.jpg"

返回（Lsky 兼容，相同图片自动秒传复用）：

{
  "status": true,
  "code": 200,
  "message": "success",
  "data": {
    "id": 42,
    "name": "photo.jpg",
    "url": "{$domain}/i/2026/11/13/xxx.jpg",
    "markdown": "![photo]({$domain}/i/2026/11/13/xxx.jpg)",
    "size": 123456, "width": 1920, "height": 1080, "reused": false
  }
}

客户端配置

PicGo / Typora

  1. PicGo → 插件设置 → 安装 lskypro（Lsky Pro 兼容插件）
  2. API 地址：{$domain}/api/v1；Token：个人中心生成的
  3. 设为默认图床即可拖图/截图直传

常见错误

提示原因
401 invalid tokenToken 不完整 / 已删除 / 已停用
400 文件不是有效图片文件不是图片或后缀与内容不符
400 日上传次数已达上限策略组日次数用尽
404 图片不存在检查链接是否完整（/i/年/月/日/文件名）
