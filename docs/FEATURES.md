## 一、上传与外链

| 功能 | 说明 | 状态 |
|---|---|---|
| 三种上传方式 | 拖拽 / 点选 / 粘贴（Ctrl+V 直接传）| ✅ |
| 双阶段进度 | 上传进度 + 服务端处理（压缩/审核/转存）分离提示 | ✅ |
| SHA1 秒传 | 同文件直接复用记录，不重复占存储 | ✅ |
| 四格式输出 | URL / Markdown / HTML / BBCode，一键复制 | ✅ |
| 外链双模式 | 代理中转（防盗链有效）/ 302 直链（零回源流量）| ✅ |
| 策略权益实时展示 | 格式 / 单图上限 / 保留天数 / 日次数 / 容量 | ✅ |
| 游客上传 | 未登录也可传（受游客组策略限制），底部提示实时读策略组 | ✅ |

## 五、站币与变现（v1.2 重点）

### 5.1 站币账户（双账户模型）

| 项 | 说明 | 状态 |
|---|---|---|
| 充值余额 `credits` | 充值所得，可消费、可提现 | ✅ |
| 收益余额 `earnings` | 作者分成所得，可提现、可消费 | ✅ |
| 消费扣款顺序 | 优先扣充值余额，不足扣收益余额 | ✅ |
| 提现扣款顺序 | 优先扣收益余额，不足扣充值余额 | ✅ |
| 双账户明细 | 流水表记录 `account`（credits/earnings）| ✅ |
| 提现记录拆分 | `from_credits` / `from_earnings` 记录扣款来源 | ✅ |

### 5.2 充值

| 配置项 | 说明 |
|---|---|
| 充值比例 | 1 元 = N 币（默认 10）|
| 最低充值 | 低于此金额拒绝下单 |
| 充值档位 | 固定金额按钮（金额/额外赠币/排序/上下架）|
| 充值活动 | **满额送币**（充 100 送 10），阶梯匹配取最高满足门槛 |
| 活动加成 | 全局百分比加成（可叠加）|
| 档位 + 活动 + 加成 | **三者叠加**，到账 = 金额×比例 + 档位赠 + 活动赠 + 加成 |
| 前台预估 | 输入金额实时显示"到账 X 币（含满额赠送 Y）"|

### 5.3 提现

| 配置项 | 说明 |
|---|---|
| 提现开关 | 关闭后前台隐藏提现标签、接口拒绝 | ✅ |
| 提现比例 | 1 元 = M 币（**独立于充值比例**）| ✅ |
| 最低金额 / 月限次数 / 手续费 | 手续费精确到分（50 × 3% = 1.50 元）| ✅ |
| 提现金额步长 | 任意整数 / 10 / 50 / 100 的倍数 | ✅ |
| 套利测算 | 后台实时显示 `(N/M)×(1−费率)−1` 净收益率，正数警示 | ✅ |
| 提现账号 | 独立保存支付宝姓名+账号，申请时自动预填 | ✅ |
| 提现记录 | 金额/手续费/实得/扣币明细/状态/驳回原因 | ✅ |
| 驳回退款 | **按原路退回**（收益部分回 earnings，充值部分回 credits）| ✅ |

### 5.4 分成

| 配置项 | 说明 |
|---|---|
| 分成模式 | 统一比例 / 按来源（自制图 vs AI 图）|
| 比例 | 作者比例、AI 图比例（独立）|
| 入账账户 | 分成进入**收益余额**（可提现）|
| 前台展示 | 收益标签显示分成比例、累计分成、可提现 |

### 5.5 付费解锁

| 功能 | 说明 | 状态 |
|---|---|---|
| 单图定价 | 作者设置付费价格 | ✅ |
| 解锁扣币 | 先扣充值余额，不足扣收益余额 | ✅ |
| 作者分成 | 按比例入账收益余额，`credits_total` 累计 | ✅ |
| 解锁记录 | 后台可查买家/卖家/价格/分成比例/时间，支持筛选+批量删除 | ✅ |

## 八、财务中心（v1.2 新增）

财务管理 8 个标签：

1. **支付网关** — 接口地址、PID、密钥、通道开关
2. **站币设置** — 充值比例/最低额/加成 + 充值档位 CRUD
3. **VIP 套餐** — 套餐编辑（价格/天数/策略组）
4. **提现设置** — 开关/比例/最低额/步长/月限/手续费/套利测算
5. **作者分成** — 分成模式与比例
6. **最近订单** — 类型/状态/渠道筛选
7. **站币流水** — 用户/类型/日期筛选 + 收支汇总 + CSV 导出 + **解锁记录**（筛选/批量删除）
8. **提现管理** — 审核/打款/驳回 + 凭证记录 + 扣币明细
