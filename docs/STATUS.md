# 全站状态总览（STATUS）

> 版本：**v1.1.0** ｜ 更新：2026-11-15
> 本文是「已完成 / 未做 / 限制」的唯一权威清单，README 只做概览，`docs/TODO.md` 记录待办及验收证据。

## 一、已完成模块

### 1. 上传与外链
- 拖拽 / 点选 / 粘贴上传，两阶段进度提示
- SHA1 秒传，同文件复用记录
- 四种输出格式（URL / Markdown / HTML / BBCode）
- 外链双模式：代理中转 / 302 直链（按存储实例配置）
- 前台实时展示当前策略组权益

### 2. 用户与策略组
- 注册 / 登录 / 退出（bcrypt），游客组与注册组可配
- 策略组：单图上限、日次数、容量、保留天数、扩展名、免广告、Token 数量（-1/0/N）
- 系统三组保护；个人中心权益面板

### 3. 存储
- 本地磁盘 / WebDAV（坚果云、Alist）多实例并存
- 配额阈值（达量停传）、空间与已用统计
- 孤立文件扫描清理（1 小时保护）、删除图片同步删文件

### 4. AI 审核与标签
- 多模型链：增删改、排序、启停、失败切换、并行投票
- 模型卡片：失败计数、最近成功时间、一键测试
- 双体系：审核模型（管理）/ 生成模型（文生图）
- 审核结论可见（模型名 + 理由）
- **标签**：短标签 2~6 字、>8 字丢弃、`[模型]` 前缀清理、任务分类自动打标
- 全部失效转人工复审（不冻结外链）

### 5. 运营与变现
- 易支付双网关 + 支付宝/微信/QQ 三通道
- VIP 套餐权益同步策略组，到期自动回组
- 广告位（四位置）、三种运营模式
- 站币充值 / 单图解锁 / 作者分成 / 提现审核
- 举报体系（AI 二次审核、按组限权、批量下架/驳回）
- 违规指纹库（SHA1 + 感知哈希）、违规次数自动停用

### 6. 开放 API
- Lsky Pro 兼容：upload / info / list / delete
- Token 三方式鉴权、调用统计、周期统计卡片
- 文档：`docs/API.md`（含 PicGo / Typora）

### 7. 后台（13 模块，统一标签页卡片布局）
仪表盘 / 图片管理 / 用户管理 / 策略组 / 存储管理 / **财务管理（5 标签）** / 支付管理 / 广告管理 / **模型设置（5 标签）** / API Token / 上传日志 / **造图任务（4+4 标签）** / **计划任务（2 标签）** / 站点设置（2 标签）
- 列表页统一「筛选 + 批量 + 单条」三件套
- 图片管理支持标题/标签/审核状态一键编辑

### 8. 造图机器人（v1.1.0 重点）
- 任务调度：提示词池、每次张数、间隔、目标账号、模型、自动公开、单日上限、失败熔断、失败重试
- 双通道：宝塔 CLI（推荐）/ 访问 URL；后台单任务「立即执行」
- 提示词池：≤2000 条、保存打乱 + 游标轮换（一轮不重复，用完从头）
- 提示词中心四子标签：AI 批量生成 / 模板随机组合 / 导入导出 / 图生文反推
- 无效图拦截（空白/纯色/过小）、明细含审核状态
- 详情预览（`gen_task_id` 归属 + 分页）、今日统计 + 7 日趋势、提示词最常用/从未抽到
- 图片标题 = 审核描述清洗（去前缀/套话/限 60 字），广场/详情/搜索/SEO 复用

### 9. SEO 与收录
- 标题：`图片标题 · 站点名`；description / OG / canonical
- 结构化数据：ImageObject + BreadcrumbList（JSON-LD，可关）
- sitemap.xml：动态 + 缓存（默认 30 分钟），仅公开通过图，支持后台配置与一键重建
- robots.txt 动态生成（按域名，不写死）
- 百度主动推送：手动增量 + 自动节流（累积条数 / 最小间隔 / 每日上限），复用 5 分钟任务
- 后台 SEO 面板（站点设置 → SEO 设置）

## 四、需要站点所有者操作（部署后）

1. 宝塔计划任务：`cd 项目根 && /path/to/php think gen:run`（每 5 分钟），脚本内容务必为真实换行
2. 百度 token 如曾公开，请在搜索资源平台重置后回填后台（本仓库代码不再包含任何 token 默认值）
3. 百度搜索资源平台 / Google Search Console 提交 `https://你的域名/sitemap.xml`
4. Rich Results Test 验证详情页结构化数据
